# La Colline des Lutins — прототип сайта

Статическая страница-прототип. Открывается двойным кликом по `index.html`.

## Как поменять фотографию

Все фото лежат в папке **`images/`**. Чтобы заменить снимок — положите свой
файл с **тем же именем** вместо старого. Ничего в коде трогать не нужно.

| Файл | Где на странице | Формат |    
|------|-----------------|--------|. 
| `images/hero.jpg`     | Большая шапка вверху        | горизонтальное (широкое) |
| `images/mushroom.jpg` | Блок «Tout un après-midi…»  | вертикальное |
| `images/forest.jpg`   | Широкий бандо с цитатой      | горизонтальное (широкое) |
| `images/goat.jpg`     | Карточка «Parrainer un animal» | вертикальное |
| `images/logo.png`     | Логотип в шапке              | PNG |

Совет: сохраняйте ту же ориентацию (горизонт/вертикаль), чтобы вёрстка не «поехала»,
и держите ширину до ~2000 px — так страница грузится быстро.

Если хотите файл с **другим** именем — откройте `index.html` в любом текстовом
редакторе, найдите строку с комментарием `<!-- PHOTO ... -->` и впишите новое имя
в `src="images/…"`.
